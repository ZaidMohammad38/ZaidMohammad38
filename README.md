## 🧩 How I Think About Software

| Question | Why It Matters |
|----------|----------------|
| 🔩 **Can it scale?** | Features that break under load are liabilities, not assets |
| 👁️ **Can I monitor it?** | Blind systems fail silently — observability is non-negotiable |
| 🤝 **Can someone maintain it?** | Code is read 10× more than it's written |
| 📦 **Is it deployable?** | Running locally isn't shipping — containers and pipelines matter |

> *"The best backend code is invisible to the user, obvious to the next developer, and loud when something goes wrong."*
